# Writee · 写作

一个为“和 AI 一起改文章”设计的本地 Markdown 写作工具：在原文件上实时编辑与渲染，按小标题切成可拖拽的嵌套卡片，框选文字写注释并用连线看清对应关系，一键把注释整理成提示词交给 AI，还能让 AI 按句子做结构标签分析。

## 快速开始

需要 Node.js 18+。

```bash
npm install
npm run dev        # 打开 http://localhost:5173
```

**Windows 桌面启动**：`scripts/launch-writee.vbs` 会在后台启动服务（`localhost:5173`，日志写入 `writee-server.log`）并用 Edge / Chrome 以应用窗口打开；运行 `scripts/create-desktop-shortcut.ps1` 可在桌面创建快捷方式。首次使用前仍需 `npm install`。

或构建成静态文件：

```bash
npm run build      # 输出到 dist/
npm run preview    # 本地预览 http://localhost:4173
```

**浏览器**：推荐 Chrome / Edge（桌面版）。它们支持 File System Access API，Writee 才能直接读写你电脑上的 `.md` 文件。该 API 只在安全上下文中可用——`localhost` 或 `https://`。如果用局域网 IP 的 `http://` 打开，或使用 Safari / Firefox，Writee 会退化为“存档模式”：可以打开文件编辑，修改保存在浏览器存档中，需要时下载 `.md`。

## 功能

### 编辑器
- 实时预览：标题、粗体、链接、列表、引用、代码块、表格、图片等即时渲染；光标所在处显示 Markdown 标记（设置里可切换为源码模式）。
- 打开本地文件后，修改约 0.7 秒后自动写回**原文件**（`⌘/Ctrl+S` 立即保存）。
- 每 2 秒检查一次文件是否被外部修改（例如让 AI 工具直接改了文件）：没有冲突时自动载入，注释和分析会按文字变化重新对齐；双方都改了会弹出选择。
- 撤销 / 重做覆盖所有操作：打字、卡片移动、注释增删等（`⌘/Ctrl+Z`、`⌘/Ctrl+Shift+Z`）。
- `⌘/Ctrl+F` 查找替换。

### 1. 标题导航
左侧大纲按标题层级显示，点击跳转，当前所在小节高亮；在大纲里按住标题拖动即可调整顺序，左右拖动改变层级。

### 2. 卡片视图
- 按小标题把文章切成**嵌套卡片**，卡片内仍是带实时预览的编辑器。
- 层级按“相对关系”计算，兼容不同 AI 的习惯：只用 `###`/`####` 的文章，`###` 就是顶层卡片；跳级（`##` 下直接 `####`）也能正确嵌套；文首唯一的 `#` 作为文章标题。
- 拖动卡片左上角的把手：上下决定位置，**左右决定层级**；移动到别的层级时，整节（含子卡片）的标题级别会自动调整。
- 卡片菜单：上移/下移、升级/降级、添加同级或子卡片、复制、去掉标题、删除（可撤销）、更改标题级别；可一键折叠到一级 / 二级。
- 快捷键（光标在卡片内）：`Alt+Shift+↑/↓` 移动，`Alt+Shift+←/→` 升降级。
- 在卡片里输入 `## 新标题`，离开卡片后会自动拆出一张新卡片。

### 3. 注释
- 选中文字 → 浮动工具条：**标签**（只打一个数字标签）、**注释**（打标签并新建注释）、**关联到…**（加入已有注释）。快捷键 `⌘/Ctrl+Alt+M`。
- 标签按在文中的顺序自动编号；一条注释可以连接多个标签。
- 右侧注释栏与正文对齐，正文旁的圆点与注释之间画出连线；悬停注释、标签或圆点时，相关的连线和文字一起高亮。
- 连接更多标签：拖动注释左侧的小圆点到正文里的标签上；或点注释上的 `+` 进入关联模式，再点正文标签（`Esc` 退出）。
- 点正文里的数字徽标可以查看/新建/关联注释、删除标签；注释支持改色、标记已解决、搜索、批量选择与删除。
- **注释和分析只保存在浏览器存档中，不会写入文件。**每篇文档都有独立存档，再次打开同一个文件（或从“最近的文档”进入）会自动恢复。

### 4. 一键复制注释给 AI
勾选注释（或直接点顶栏“复制注释”），选择上下文范围：

- **相关段落**：只带批注所在段落和它的标题路径（默认）；
- **全文**：附上整篇文章；
- **仅引文**：只列出被批注的文字。

原文中用 `【n】…【/n】` 标出批注位置，后面逐条列出注释。可以附加一句指令（如“按批注修改全文”）。

如果你在本编辑器里**手动**改过文章，提示词末尾会加上：“我做了一些修改，注意不要替换成原来的文字，必要的话可以修改。”并列出改动所在的句子。只有在 Writee 里的手动输入会被记录；外部对文件的修改不算。改动痕迹可在状态栏 / 设置中显示或清除。

### 5. 结构标签分析
- 以句子为单位（一句或多句）标注：论证要素、论证方法、结构功能、表达方式、修辞、写作技法、语气立场，以及“问题诊断”（论证薄弱、逻辑跳跃、套话/AI 腔……），共 8 类 90 个标签。
- **BYOK，通用接口**：在“AI 设置”里选择接口格式，填 Base URL、API Key 和模型名即可，官方服务与第三方中转都能接：
  - **OpenAI 兼容**：请求 `{Base URL}/chat/completions`，如 OpenAI、DeepSeek、OpenRouter、通义千问、Kimi、智谱、硅基流动、本地 Ollama；
  - **Anthropic 兼容**：请求 `{Base URL}/v1/messages`（与 `ANTHROPIC_BASE_URL` 的写法一致），如 Anthropic 官方，或 DeepSeek / Kimi / 智谱等提供的 Anthropic 接口。
  - 提供“快速填写”预设、“获取列表”（读取服务端模型列表）和“测试连接”。
  - 高级：最大输出 tokens、认证方式（x-api-key / Bearer）、额外请求参数（JSON，原样合并进请求体）。
  - 只有 Base URL 是官方 `api.anthropic.com` 时，才会附加官方专属参数（自适应思考与思考深度、服务端兜底、提示词缓存），第三方服务只收到标准参数。
  - 配置与 Key 只保存在本机浏览器里，请求从浏览器直接发往服务商。
- 结果流式写入：边分析边在正文中出现彩色下划线，右侧栏对齐显示标签，点击可查看作用说明与修改建议、增删标签；图例可按类别筛选。
- 没有 API Key 也能用：“复制分析提示词”交给任意 AI，再把回复粘贴到“导入分析结果”。
- 选中文字后可以手动标注（自动扩展到整句）。
- 分析结果可导出为标准文件，格式见 [docs/structure-format.md](docs/structure-format.md)。

> 有些服务不允许浏览器跨域直连（报“无法连接”）。用 `npm run dev` / `npm run preview` 启动时，可在 AI 设置里勾选“通过本地代理转发”。长文分析若提示“输出被截断”，在“高级”里调大最大输出 tokens。

### 界面
- 左侧大纲、右侧注释/结构栏都可以**拖动边缘调整宽度**，双击边缘恢复默认；宽度会被记住。
- 卡片移动、折叠展开、增删，注释与标签的出现，模式与侧栏切换都有平滑动效；跳转标题或标签时平滑滚动。系统开启“减少动态效果”时自动关闭动画。

### 外观
5 套配色（宣纸、素白、青瓷、暮山、墨夜），可调字号、行距、版心宽度。正文字体为思源宋体（Noto Serif SC）+ Instrument Serif（西文），均随应用打包、按需加载；如果系统装有思源宋体，会优先使用本地字体。

## 数据存放在哪里

| 内容 | 位置 |
| --- | --- |
| 文章正文 | 你打开的 `.md` 文件本身 |
| 注释、标签、结构分析、修改痕迹、卡片折叠状态 | 浏览器 IndexedDB（数据库 `writee`），按文档分别存档 |
| 外观设置、AI 设置（含 API Key） | 浏览器 localStorage |

清除浏览器站点数据会丢失注释与存档；在欢迎页“最近的文档”中可以删除单个存档（不影响原文件）。

## 开发

```bash
npm run typecheck
npm test           # 核心逻辑单元测试（vitest）
npm run e2e        # 端到端测试（需先 npm run dev；使用本机 Chrome，或设置 CHROME_PATH）
```

接手开发请先读 [AGENTS.md](AGENTS.md)（架构、关键约定、进度与待办）。

主要目录：

- `src/core/` 小节解析、切句、位置映射、卡片移动、提示词生成、存档
- `src/editor/` CodeMirror 6 实时预览、注释/结构/修改痕迹的装饰层
- `src/store/` 文档状态（含全局撤销）、界面状态、文件同步
- `src/components/` 界面：卡片、注释栏与连线、结构栏、对话框
- `src/analysis/` 标签体系、分析提示词、AI 调用、分析文件格式
