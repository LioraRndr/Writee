## 2026-10-29 · 公式导致的点击错行

- **现象**：用户反馈点击正文时光标落不到对应的行，怀疑与 LaTeX 有关。写了逐行点击探针（对每个可见行取文档行号，再点击并读取光标所在行），在含行内公式、公式块、段落中显示公式、跨行公式、`aligned` 环境的文档上复现。
- **原因一**：`$$` 可以跨行；夹在段落中间的跨行 `$$…$$` 不满足“独占整行”，被 `inlinePlugin` 当作行内替换装饰，覆盖了换行符。CodeMirror 禁止视图插件这样做，在 DOM 更新途中抛 `RangeError: Decorations that replace line breaks may not be specified via plugins`，之后屏幕与内部状态不一致。修复：新增 `spansLines`，插件跳过跨行公式；`mathBlockField`（StateField，可替换换行）负责所有跨行公式，整行的用块级部件、其余用行内部件。
- **原因二**：公式块（`margin: 0.65em 0 1em`）和表格（`margin: 0.55em 0 1.15em`）用 margin 留间距。CodeMirror 测量块级部件高度时不计 margin，高度表每遇到一个就少一截；对比 DOM 位置与 `lineBlockAt().top`，6 组公式 + 表格后偏差累计 362px，点击按高度表换算行号，越往下错得越多。修复：公式块改为等量 padding；表格部件新增只有 padding 的根节点 `.cm-table-block`（控制器同时登记根节点与 `.cm-md-table`），视觉间距不变。修复后所有行偏差为 0，探针 13 行全部命中（编辑与卡片两种模式）。
- **测试**：`editing` 新增 `formulaPositions`（两种模式）：段落中的跨行公式渲染且无页面错误、高度表与实际行位置一致、点击 5 组公式与表格之后的最后一行时光标落在该行。分别只回退插件修复（报 RangeError）和只回退间距修复（偏差 0→60→…→301px）确认用例能抓到两个问题。卡片编辑器会虚拟化屏幕外的行，用例先滚到相应位置再检查。类型检查、19 项单元测试、生产构建通过；云端 9 组 E2E 中 7 组通过，`file-sync`、`workspace` 仍因容器 Chromium 的 OPFS 句柄问题无法运行。
- 上一轮 PR 已合并，本分支从最新 `main` 重新开始；推送到 `claude/adoring-thompson-ml3vu0`，未部署线上。

## 2026-10-28（二）· 宽表格出界、表格宽度自适应、窄屏左侧栏挤压正文

- **复现**：6 列长文字表格在编辑模式下 `.cm-content` 为 895px，而版心只有 592px，正文伸到注释栏下面；卡片模式里内容区 869px，卡片只有 542px，表格前后的正文一起跳出卡片。根因是 CodeMirror 的内容区是 flex 子项，`min-width: auto` 等于最宽内容的最小宽度；上一轮重写表格样式时去掉了原来的 `container-type: inline-size`，还给每列加了最小宽度，表格最小宽度因此向上撑开整个编辑器。

- **窄屏左侧栏**：≤900px 时不再 `position: absolute` 覆盖，留在文档流中挤压右侧正文，宽度用 `--outline-eff = min(--outline-w, 46vw)`（大纲、左侧标签页、切换开关共用）。右侧注释栏仍覆盖、两侧互斥。原先每次 Workspace 挂载（多标签页切换时每次都会）都会在窄屏下收起侧栏，改为只在进入窄屏或首次以窄屏打开时收起（模块变量 `lastNarrow`）。窄卡片头部“N 张子卡片”改为单行省略，不再逐字竖排。
- **测试**：`editing` 新增 `wideContent`（两种模式：内容区不被撑宽、正文不出卡片 / 版心、12 列表表内滚动、长格表格占满可用宽度、窄表收缩、短格单行、页面无横向溢出），先暂存源码修复在旧代码上确认会失败；拖选用例改为先把表格滚到视口中间（鼠标 API 不自动滚动，表格变窄后起点落到了标签栏下）。`layout` 改为断言左侧栏挤压正文、宽度封顶、页面不溢出、新开标签页后大纲保持打开，并保留右栏覆盖与两侧互斥。类型检查、19 项单元测试、生产构建通过；云端 9 组 E2E 中 7 组通过，`file-sync`、`workspace` 仍因容器 Chromium 读取 IndexedDB 里的 OPFS 句柄崩溃而无法运行。
