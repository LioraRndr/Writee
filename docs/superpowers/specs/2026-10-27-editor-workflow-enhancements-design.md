# Writee 编辑与本机工作流增强设计

日期：2026-10-27

## 目标与边界

在保留 React、CodeMirror、全文 DocData、全局撤销、注释定位、卡片结构与五套主题的前提下，一次完成六项增强：LaTeX 渲染、渲染表格完整编辑、嵌套卡片展开动画修复、文件标题菜单增强、Ctrl+点击链接系统打开、窄屏自适应。

用户已明确：本机启动器提供完整系统能力；纯网页/线上环境明确降级；表格包含内容、结构、拖放和网格复制粘贴；Ctrl+点击时 Markdown 也遵循系统默认关联。后续设计取舍由实现者按现有产品风格决定，不再增加询问轮次。

## 1. LaTeX

- 新增 KaTeX，不手写 TeX 排版。支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]`。
- 公式扫描排除代码块、行内代码、图片与 HTML；转义 `\$` 不成公式。源 Markdown 不变。
- 编辑与卡片共用块级/行内部件，光标进入公式范围时显示源码。表格单元格复用同一渲染入口。
- KaTeX 不信任不可信 HTML；错误公式显示源码与错误提示，不影响其他内容。
- 块级公式可横向滚动，行内公式不撑破正文；颜色继承主题。

## 2. 渲染表格完整工具

新增纯表格模型和独立 CodeMirror Widget。模型负责 GFM 行列解析、转义、对齐、序列化、结构操作、TSV 解析与生成；Widget 负责呈现和交互。

- 单击单元格编辑，Enter/失焦提交，Esc 取消，Tab 顺序移动；提交后可用方向键移动、Shift 扩展选区。
- 支持行列增删、表体行拖放、列拖放、列对齐；不把表头分隔行当普通数据编辑。
- Ctrl+C 将所选网格复制为 TSV；Excel/剪贴板 TSV 可从活动格粘贴并自动扩展所需行列。另保留整张 Markdown 表格复制。
- 单元格换行写回 `<br>`，竖线写回 `\|`；TSV 支持引号、CRLF 和带换行的字段。
- 每次提交、结构操作、拖放或粘贴只产生一个 CodeMirror 事务。用 `diffChanges` 生成最小差异，经现有 updateListener 进入 `applyChanges`，从而保留撤销、自动保存和注释映射。
- 编辑期间不闪回整张源码表。表格保留语义 table/thead/tbody，窄容器自身滚动，不改成破坏行列关系的卡片布局。

## 3. 卡片展开动画

根因范围：当前只给被切换卡片本身做高度动画，嵌套展开时祖先高度立即跳到终值；新子卡还叠加缩放和位移，造成边框、内容与后续兄弟不同步，呈现回弹感。

- 高度动画集合包含被切换卡片及所有需要同步的祖先卡片。
- 所有高度和 FLIP 位移采用同一时长、同一非回弹曲线；新子卡仅轻微淡入/位移，不再缩放。
- 连续快速切换先管理旧动画，避免过期动画完成回调恢复新状态。
- 折叠按钮同步 `aria-expanded`，减少动态效果时仍立即完成。

## 4. 文件标题菜单

保留打开、新建、工作目录、保存、下载、关闭，补充：

- 另存为；
- 复制文件路径；
- 在文件夹中显示并选中当前文件；
- 用系统默认方式打开当前文件。

仅本机启动器授权的 `LocalFileHandle` 提供真实绝对路径与系统操作。浏览器 File System Access 句柄不伪造路径，相关项禁用并注明“本机入口”。操作成功/失败均给明确提示。

## 5. 链接与文件索引

- 覆盖行内 Markdown 链接、裸 URL、自动链接、表格链接和 `[[路径]]` / `[[路径|别名]]`。
- 普通点击保持编辑光标；Ctrl/Cmd+点击才打开，避免与文字编辑冲突。
- 本机模式下，http/https/mailto 和本地文件均通过受限本机接口调用系统默认程序；纯网页仅 http/https/mailto 用浏览器打开，本地链接明确提示不可用。
- 本地相对路径以当前 Markdown 所在目录解析；支持绝对路径与 file URL，目标必须存在。非法协议、无效编码、缺失目标显示错误。
- 本机接口继续校验 localhost、Origin、Sec-Fetch-Site、能力令牌和请求大小；OS 调用使用无 shell 的参数数组，避免路径中的 `&`、空格等形成命令注入。

## 6. 窄屏自适应

- 宽屏保留三栏顶栏；中等宽度缩短文件名和按钮文案；窄屏顶栏分为“文件/操作”和“模式切换”两行。
- 最窄宽度把 AI、外观和侧栏开关收进同一更多菜单，注释、结构、复制和撤销仍可达，不用 CSS 复制两套可聚焦控件。
- 小屏大纲和右栏改为覆盖层，不长期占用正文宽度；正文页边距和状态栏信息按宽度收缩。
- 不横向挤压或覆盖控件，320px 宽度仍无页面级横向溢出；表格和公式在自身区域滚动。
